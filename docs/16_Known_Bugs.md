# Известные баги

Найдены при рефакторинге. Проверка — headless Chrome, сравнение с версией до исправления.

## Исправлено

| Баг | Как проявлялся | Коммит |
|-----|----------------|--------|
| Клонирование контейнера падало | `originalContainer.clone is not a function`: контейнеры из тестовых данных, импорта и формы создания были обычными объектами | `3d2f04e` |
| Цвет контейнера терялся | `Container` не хранил `color`; после перезагрузки у всех контейнеров `color: null` | `3d2f04e` |
| Клон «с содержимым» был пустым | Клонировались поля старого формата ячеек, `items` терялись (19 деталей → 0), у объединений терялись `startIndex`/`direction` | `3d2f04e` |
| XSS через пользовательские данные | Названия контейнеров, partId, URL изображений и т.п. (в т.ч. из импортированного JSON) вставлялись в `innerHTML` без экранирования; тестовый payload выполнялся 7 раз | `0ee98b8` |
| Автокомплит падал на спецсимволах | Ввод `(`, `[`, `*` и т.п. ломал `new RegExp` при подсветке совпадений | `0ee98b8` |
| Автокомплит деталей в куче | В подсказках `undefined - undefined`, при выборе подставлялся `undefined` | `0ee98b8` |
| Не работал fallback изображений в куче | Проверка `img.src !== originalSrc` всегда была ложной | `0ee98b8` |
| Битая картинка поверх заглушки | `display: block !important` у `.cell-image(-small)` перебивал `display: none` из обработчиков ошибок; в ячейках было видно битое изображение с alt `undefined` | `63807f3` |
| Медленная первая загрузка каталога | Запись в IndexedDB шла транзакциями по 100 записей с ожиданием каждого `put`: 30.8 с → 21.9 с (чистый профиль, headless Chrome) | `7cb0596` |
| Захардкоженная сессия BrickLink | Session cookie лежал в `scripts/bricklink_python_fetcher.py` (остается в истории git) | `f22b670` |

## Открыто

| Баг | Как проявляется |
|-----|-----------------|
| Смешение версий JS после деплоя | Модули подключаются без версий; GitHub Pages кэширует на 10 минут, и браузер может взять новый `main.js` со старым закэшированным модулем — инициализация падает |
| Обмен местами объединенной ячейки | `CellDragDrop.handleCellSwap` переносит объект объединения на другой индекс, но `startIndex` остается старым |
| Первая загрузка ~20 с | Запись каталога в IndexedDB (детали ~10 с, связи деталь-цвет ~9 с). Дальше ускорять — убирать неиспользуемые индексы (`parts`: name, catId, blId, nameAndId; `partColors`: hasImg, partId_hasImg) с повышением версии схемы. Поиск деталей при этом идет полным перебором курсором |
| Конвертеры каталога расходятся | Приложение использует формат `tab_to_lcx_converter.py`; `tsv_to_lcx_converter.py` дает другой формат (нет `hasImg`, части полей цветов) |
