# Правила работы с репозиторием

## Начало сессии
- Первым делом выполни `git fetch origin` и `git pull` (или сравни с `origin/main`), прежде чем анализировать или менять код. Проект правится из нескольких сессий и устройств; локальная копия может отставать, а `git status` без fetch показывает устаревшую синхронизацию.
- Если локальная ветка разошлась с `origin`, сначала сообщи об этом пользователю, не начинай работу поверх устаревшего кода.
